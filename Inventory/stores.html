Stores

The Stores represent the places where products are stored and managed within the system.

A store can be a physical warehouse, a pharmacy branch, or any location where inventory is handled. In this system, stores also represent different branches of the business.

Each store can have its own data such as address, email, and currency, allowing flexible management across multiple locations.

Store Operations (CRUD)

The system allows full management of stores including creating, updating, and deleting store records.

Create Store

Users can create a new store by entering the required information such as name, code, address, email, and currency.

Update Store

Existing store information can be updated at any time. This allows modifying details like store name, address, or contact information.

Delete Store

Stores can be deleted when they are no longer needed. This action removes the store from the system.
