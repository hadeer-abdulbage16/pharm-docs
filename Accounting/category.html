Category Management

The Category Management module in eStock provides a centralized interface for pharmacists and administrators to organize and manage product categories efficiently. Categories help streamline inventory tracking, reporting, and product organization within the pharmacy.

Key Features

Add Category

Create new product categories with custom names and descriptions.

Edit Category

Modify existing category details including name, description.

Delete Category

Safely remove unused categories with confirmation safeguards.

Search Categories

Quickly find categories using name-based search functionality.

Workflow

Follow these steps to manage categories effectively in eStock:

1
Access Category Management

Navigate to Inventory → Category Management from the main dashboard.

2
Browse & Search

Use the search bar or browse the category list to locate specific categories.

3
Add, Edit or Delete

Click "Add New" to create categories or use action buttons for existing ones.

4
Save & Verify

Review changes and save. System provides instant feedback on success/failure.

Add New Category

Creating new categories helps organize products logically. Follow these steps to add a category:

  1. Click the "Add New Category" button
  2. Enter the Category Name (required)
  3. Add optional Description for reference
  4. Click "Save Category"

Add Category Form Screenshot

Edit Category

Modify existing categories to reflect changes in pharmacy organization or product grouping:

  1. Locate the category in the list
  2. Click the Edit () button
  3. Update Name, Description
  4. Click "Update Category"
Note: Changes are immediately reflected in product listings.

Edit Category Form Screenshot

Delete Category

Remove unused categories safely with built-in protections:

  1. Select the category to delete
  2. Click Delete () button
  3. Confirm in the deletion dialog
  4. Category is permanently removed
Important: Categories with assigned products cannot be deleted until products are reassigned.

Validation Rules

Required Fields
  • Category Name - 3-50 characters
Optional Fields
  • Description - Max 255 characters
Common Validation Errors:
  • Duplicate category names not allowed
  • Category name must contain only letters, numbers, and spaces
  • Minimum 3 characters required for category name

Important Notes

Best Practices
  • Use descriptive category names
  • Keep category hierarchy simple (max 3 levels)
  • Regularly review inactive categories
Security
  • Only Admin & Inventory Manager roles can manage categories
  • All actions are logged in audit trail
  • Soft delete prevents accidental data loss
