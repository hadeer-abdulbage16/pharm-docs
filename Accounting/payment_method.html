Payment Method Management

The Payment Method Management module in eStock provides pharmacy administrators with a comprehensive interface to manage all available payment options within the system. This module enables the creation, modification, and maintenance of payment methods used for processing customer transactions, ensuring flexibility and control over payment configurations.

Key Features

Add Payment Method

Create new payment methods with custom configurations

Edit Payment Method

Modify existing payment method details and settings

Delete Payment Method

Remove unused or obsolete payment methods safely

Search Payment Methods

Quickly locate payment methods by name

Workflow

1
Access Payment Methods

Navigate to Settings → Payment Methods from the main dashboard

2
Browse & Search

View all payment methods or use search functionality to filter results

3
Manage Methods

Add new methods, edit existing ones, or delete unused methods

4
Save & Activate

Save changes and activate payment methods for customer use

Add Payment Method

To add a new payment method, click the "Add New Payment Method" button located at the top-right of the payment methods list. This opens a comprehensive form where you can configure all necessary details for the payment method.

Add Payment Method Form Screenshot

Tip: Always test newly added payment methods in sandbox mode before enabling them for live transactions.

Edit Payment Method

To modify an existing payment method, locate the method in the list and click the Edit button (pencil icon). Update the required fields and save your changes. The system will validate all modifications before applying them.

Edit Payment Method Screenshot

Delete Payment Method

To delete a payment method, click the Delete button (trash icon) next to the method. A confirmation dialog will appear to prevent accidental deletion. Only payment methods with no active transactions can be deleted.

Important Notes

Best Practices

Enable only verified payment methods. Always maintain at least one active cash payment option as backup.

Transaction History

Payment methods with transactions in the last 30 days are automatically protected from deletion.

Security

All payment method changes are logged with admin user ID and timestamp for audit purposes.

Customer Impact

Deactivating a payment method will immediately prevent new transactions using that method.
