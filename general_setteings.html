General Settings

The General Settings module is used to configure system-wide options such as currency, stores, financial settings, and operational preferences.

Endpoint

POST /settings/general/store

Request Parameters

Field Type Required Description
titlestringYesApplication name
timezonestringNoSystem timezone
currency_idintegerNoCurrency ID
currency_precisionintegerNoDecimal places
currency_symbol_placementstringNobefore / after
default_purchase_store_idintegerNoPurchase store
default_sales_store_idintegerNoSales store
allow_expired_productsbooleanNoAllow expired products
prevent_expired_salesbooleanNoPrevent expired sales
expiry_date_warning_enabledbooleanNoExpiry warning
return_days_limitintegerNoReturn days
show_payment_summary_on_savebooleanNoShow payment summary
cash_supply_account_idintegerNoSupply account
cash_expense_account_idintegerNoExpense account
incoming_cheques_account_idintegerNoCheques account

Example Request

{
  "title": "eStock",
  "timezone": "Africa/Cairo",
  "currency_id": 1,
  "currency_precision": 2,
  "currency_symbol_placement": "before",
  "default_purchase_store_id": 1,
  "default_sales_store_id": 1,
  "allow_expired_products": true,
  "prevent_expired_sales": true,
  "expiry_date_warning_enabled": true,
  "return_days_limit": 7,
  "show_payment_summary_on_save": true,
  "cash_supply_account_id": 1,
  "cash_expense_account_id": 2,
  "incoming_cheques_account_id": 3
}

Notes

  • Settings are global.
  • Only one record exists.
  • Checkbox values handled automatically.
